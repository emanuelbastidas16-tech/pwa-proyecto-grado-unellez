# PWA - Gestión y Evaluación de Propuestas de Proyecto de Grado (UNELLEZ)

Aplicación Web Progresiva desarrollada con Vue.js 3 (ESM/CDN), Supabase (PostgreSQL) y la API de WhatsApp para la automatización del flujo de postulación, filtros metodológicos, votación colegiada y defensa presencial de propuestas de grado.
